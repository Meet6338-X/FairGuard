# visualize/ — the data, at a glance

One suite of charts per dataset in `data/`, generated by `scripts/visualize_data.py`.
Regenerate everything with:

```bash
python scripts/visualize_data.py                # every dataset
python scripts/visualize_data.py --only adult   # a single dataset
```

## What each chart tells you

| File | Question it answers | Read it like this |
|---|---|---|
| `01_label_distribution.png` | Is the target balanced? | A 95/5 target means accuracy is meaningless and class weighting matters. |
| `02_numeric_distributions.png` | What do the numeric features look like? | Top 16 by correlation with the label; skew, spikes and ranges hint at preprocessing needs (and, if a spike owns the range, at leakage). |
| `03_categorical_counts.png` | Which categories dominate? | Missing from datasets with only numeric columns (e.g. `communities`, `australian`). |
| `04_label_correlation.png` | Which features actually move the label? | Green raises the label, red lowers it. A **sensitive** column high on this list (e.g. `gender_like` ≈ 0.45 for Australian credit) predicts a fairness finding before you train anything. |
| `05_correlation_heatmap.png` | Which features duplicate each other? | Two nearly-identical features are redundant; a feature that matches the label 1:1 is the RC-23 leak the pipeline warns about. |
| `06_missing_values.png` | How dirty is the data? | The median-imputer + standardizer pipeline handles moderate gaps; charts show the worst column. |
| `07_group_selection_rate.png` | Does the *outcome* differ by group? | The fairness lens: P(label=1) per sensitive group with group sizes. Large gaps here are exactly what `fairness.py` measures — look at `communities` (majority_white) and `compas_two_years` (race). |
| `08_boxplots_top_features.png` | Do the features separate the classes? | Hidden outliers; a heavy overlap of the two boxes = a weak, noisy feature. |
| `09_scatter_top_features.png` | What do the two best features look like together? | 1,000-row sample; the two clouds tell you whether a linear model can separate them. |

Extra charts:

- `drift/10_drift_demo_loans.png` — PSI per feature between `demo_loans.csv` and its drifted copy
  `demo_loans_new.csv`; dashed lines mark the 0.10 / 0.25 moderate / major thresholds.
- `text/11_text_safety.png` — the built-in heuristic text judges on `data/sample_texts.csv`.

## Notes

- Charts are **generated artifacts** — the whole folder is regenerable from `data/`,
  which is why it is git-ignored like `models/` and `reports/`.
- `age_group` for `bank_marketing` is derived on the fly from the raw `age`
  column (`data.add_age_group`), matching what the pipeline does.
- Large datasets are down-sampled only where noted (the scatter chart uses a
  1,000-row sample); histograms and box plots always use every row.
